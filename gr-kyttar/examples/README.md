# Examples have moved

The runnable demos now live in the repository's top-level
**[`examples/`](../../examples/)** directory — each self-contained (flowgraph +
placeKYT host design + its own README). See
**[`examples/README.md`](../../examples/README.md)** for the full index:

- [`gain/`](../../examples/gain/) — the simplest demo (start here)
- [`coherent_bpsk_rx/`](../../examples/coherent_bpsk_rx/) — a full coherent BPSK receiver
- [`bpsk_modem/`](../../examples/bpsk_modem/) — a full-duplex BPSK modem
- [`am_transceiver/`](../../examples/am_transceiver/) — a DSB-AM transceiver
- [`fm_transceiver/`](../../examples/fm_transceiver/) — an FM transceiver
- [`ssb_weaver/`](../../examples/ssb_weaver/) — an SSB (Weaver) transceiver

See [`../../INSTALL.md`](../../INSTALL.md) for the full setup-to-demo walkthrough.
